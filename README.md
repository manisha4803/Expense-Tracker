# My Expense Tracker

A dark-themed **Financial Report Dashboard** built using only **HTML and CSS**.  
This project focuses on clean layout, spacing, alignment, and Flexbox-based UI design.

## Project Overview

The dashboard is designed like a financial report. It includes:

- a header section
- a compact current balance card
- summary cards
- expense categories
- recent financial activities

The interface is fully static and does not use JavaScript.

## Features

- Dark mode financial dashboard UI
- Header with report title
- Current balance card
- 3 summary cards displayed with Flexbox
- Expense categories section
- Recent financial activities section
- Responsive layout for smaller screens
- Smooth, clean visual hierarchy

## Tech Stack

- HTML5
- CSS3
- Flexbox
- Box Model
